# Privacy

MapLiberator doesn't collect any data about you. The extension has no analytics, telemetry or crash
reporting, there's no account to create, and it never sends anything to us or to anyone else. When
you run an export, it talks only to the mapping service you're exporting from, signed in as you,
and writes the archive straight to your computer. There is no MapLiberator server, so your tracks,
photos and account details never pass through one. This website sets no cookies and runs no
analytics. Vercel, which hosts it statically, keeps routine request logs for a short time, and we don't use
them for anything. The code is [on GitHub](https://github.com/mapliberator/extension) if you'd like
to check.
